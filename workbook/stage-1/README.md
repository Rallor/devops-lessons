# Етап 1. PoC → перший живий стенд (тижні 1–6)

## Тригер

Розробники віддали застосунок, який працює в них на ноутбуці. За два тижні його показують стейкхолдерам за адресою в інтернеті, і демо не має впасти.

## Свідомий компроміс

Усе налаштовується **руками** на одній VM (Ubuntu 26.04 LTS, створена через портал). Це технічний борг, який ми беремо усвідомлено: він стане тригером Етапу 2. Але кожен ручний крок потрапляє в `runbook.md` — на Етапі 2 цей файл стане специфікацією для Ansible.

## Вимоги етапу (NFR)

1. Застосунок, воркер і фронтенд доступні за доменом лише по HTTPS; HTTP → 301.
2. Сертифікат оновлюється автоматично, строк дії моніториться з алертом за 14 днів.
3. API і воркер — systemd-сервіси під окремими системними користувачами без shell і sudo; піднімаються після reboot; перезапускаються при падінні.
4. Рестарт застосунку не дає користувачу 502 (два інстанси за nginx upstream).
5. SSH лише по ключу, без root-логіну, доступ через bastion. Firewall default-deny: назовні 80/443.
6. PostgreSQL не слухає публічний інтерфейс; дані на окремому LVM-томі, який розширюється без зупинки.
7. Щоденний бекап за systemd timer; restore перевірено на чистій машині, час записано.
8. Зовнішній uptime-check шле алерт у Telegram.
9. Security-оновлення ставляться автоматично з контрольованим вікном перезавантаження.
10. Листи застосунку проходять SPF, DKIM, DMARC.

## ADR етапу

- **ADR-001.** Де і на чому хостимо стенд: VM vs PaaS; Ubuntu 26.04 vs Debian 13 vs RHEL-сумісний; nginx + certbot vs Caddy.
- **ADR-002.** Розмітка диска під дані БД: розділ vs LVM, ext4 vs xfs.
- **ADR-003.** Правила репозиторію: захист `main`, PR, pre-commit.

Шаблон — `templates/adr.md`. Ревʼю — `prompts/03-adr-review.md`. ADR без розділу «Наслідки» не приймається.

## Ворота етапу

```bash
./verify/run.sh 1              # усі автоматичні перевірки
cat verify/stage-1/manual.md   # те, що доводиш артефактом
./incidents/inject.sh 1        # інцидент етапу, потім постмортем
```

Етап закрито, коли зелені всі перевірки, ADR-001…003 змерджені, postmortem написаний, AI-політика (одна сторінка) лежить у репозиторії.
