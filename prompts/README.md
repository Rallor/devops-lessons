# Промпти

Кожен файл — окрема роль. Не змішуй їх в одному чаті: тьютор, який щойно давав підказки, гірше тебе екзаменує.

| Файл | Коли використовувати | Новий чат? |
|---|---|---|
| `00-tutor-system.md` | Системний промпт для всіх ролей нижче | — |
| `01-hints.md` | Застряг і вичерпав ліміт часу | ні |
| `02-code-review.md` | Блок зроблено, `verify` зелений | так |
| `03-adr-review.md` | ADR написано | так |
| `04-quiz.md` | Ревʼю пройдено, закриваєш блок | так, без документації поруч |
| `05-incident-master.md` | Після `inject.sh`, якщо зайшов у глухий кут | ні |
| `06-postmortem-review.md` | Постмортем написано | так |
| `07-mock-interview.md` | Наприкінці етапу або курсу | так |

**Головне правило.** До кожного ревʼю додаєш `verify-report.md` і реальні файли (юніти, конфіги, код). Опис словами «я налаштував» не є вхідними даними: тьютор інструктований його не приймати.
